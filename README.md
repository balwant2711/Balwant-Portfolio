# Balwant Singh — DevOps / Cloud Portfolio

A responsive resume + portfolio website built with HTML, CSS and JavaScript.

## Design refresh
- Warm ivory / paper background rather than a pure-black dark theme
- Deep navy typography and panels, teal and coral accents, soft lilac details
- Editorial layout, rounded cards, subtle texture and layered gradients
- Responsive navigation, reveal animations, floating hero elements and 3D tilt
- Resume PDF included at `assets/Balwant-Singh-Resume.pdf`

## Run locally
Open `index.html` in a browser, or serve this folder with a local static server.

## Deploy to GitHub Pages
Upload the contents of this folder to the root of your repository and commit to the branch configured for GitHub Pages.
